Sibyl Privacy Policy

Effective date: 11 November 2026
Operator: __v33__
Contact: theaft3rmath@proton.me

Sibyl is a small, hobby Discord bot: a joke chatbot with some Warframe information, a few fun commands and a few moderation tools. This page explains what it does with information. In short: it keeps very little, it keeps it anonymously where it can, and it never sells it. It is only shared in the limited ways listed in section 4, which include AI tools used to assist development.

The same summary is available inside Discord with the /about command.

1. What the bot can see

To work, the bot must be allowed to read messages in the channels it can access (Discord's "Message Content" permission) and to see members and their roles (Discord's "Server Members" permission). It looks at most messages only for one purpose, the banned-emoji check described in section 3, and saves nothing from them (section 3 also explains the short-lived memory cache). It only responds to messages that mention it or reply to it.

2. What the bot stores

a) Feedback you choose to send. Messages you send to the bot in chat are not saved. The only text it keeps is what you deliberately send with /feedback (up to 1,000 characters), so the operator can read it and improve the bot. Each entry contains only:

  • the text, after the bot removes mentions and @handles, links with or without "https://", e-mail addresses, IP addresses and numbers of seven or more digits;
  • the date (no time of day);
  • a "moderator" flag if a moderator sent it.

It does not contain your name, user ID, server, channel, message ID or exact time. Feedback containing words on the bot's slur list is never saved. Entries are deleted from the bot's files automatically after 30 days (section 5 explains what that does and doesn't cover).

The cleaning is automatic and cannot catch everything, for example a name typed in plain text, so please don't put personal information in feedback.

Feedback is read by the operator, for debugging and improving the bot, and may be processed by AI tools used to assist development (see section 4). It may also be kept and used where necessary for legal, safety or security reasons, for example to investigate abuse or to respond to a lawful request.

b) Your storage opt-out. /optout storage stops /feedback from saving anything from you, turns off the short-term conversation memory described in section 3 and leaves you out of the usage totals in section 2g. To remember your choice, the bot stores a one-way keyed hash of your Discord user ID (not the ID itself) and nothing else about you (the only other thing that can be stored about you is the temporary slur-warning and ban record described in section 2h, if you have one). It is kept until you opt back in with /optin storage, or delete it yourself at any time with /forgetme (that puts you back to the default).

c) Server settings. For each server it is in, the bot stores the choices that server's administrators make with /settings: whether the welcome message is on, which picture it uses, which game the server is mainly about, and role and channel IDs (moderator roles, the mute role, the notice channel, roles /giverole may hand out). It also stores that server's banned-emoji list. This contains no information about any person. It is kept until the bot is removed from the server (or you ask for it to be deleted).

d) Mood. The bot has a daily "mood" number for each server. It stores only the server ID, the date and the number. It is nudged up or down by friendly or rude messages, but nothing about who or what caused it is kept.

e) Picture reports. If you report one of the bot's cat or dog pictures, the bot stores the picture's file name, the reason you picked from a fixed list, the date and how many times it has been reported. It does not store who reported it, and there is no free text. A report is deleted when the operator closes it.

f) Servers that removed the bot. If the bot finds saved data for a server it is no longer in, it stores that server's ID and the time it first noticed (data/departed.json), so it can delete that data after 7 days (see section 6). This contains no information about any person, and the entry is removed once the data is deleted or the bot returns to the server.

g) Anonymous usage totals. So the operator can see how the bot is doing, it keeps global totals for each day (UTC): how many times each command was used or crashed; how many chat replies it sent to people who pinged or replied to it, how many of those messages it didn't understand, and which kinds of reply it used (labels for the bot's own replies, such as "joke-reply"); how many servers it is in, joined and was removed from; how many people have opted out; and how often it restarted, how long it ran, its connection latency and how often warframestat.us failed. These totals contain no user ID, name, server, channel, message ID, exact time or anything anyone wrote, and they are not broken down by person or server. Messages that aren't addressed to the bot are not counted. People who have used /optout storage are not counted, and activity in the operator's private admin server is left out. Only the operator can view the totals, and each day's totals are deleted after 12 months.

h) Slur warnings and bans. If you send the bot a message containing a word on its slur list, the bot doesn't answer it normally, doesn't save it, and counts it as a warning. Three warnings within 24 hours ban you from using the bot (chat and commands, in every server and in DMs) for 7 days. To enforce the ban, the bot saves a small record on disk: a one-way keyed hash of your Discord user ID (not the ID itself), the times of your recent warnings and, if you are banned, the time the ban ends. It does not contain the message, your name, a server, channel or message ID. Warnings are deleted after 24 hours and a ban when it ends, so nothing is kept longer than 7 days, and expired records are deleted automatically. The record exists only to enforce the ban and to prevent abuse of the bot. For that reason it applies even if you used /optout storage, and /forgetme doesn't remove it (otherwise a ban could be erased on demand). If you think a warning or ban is a mistake, contact the operator and it will be deleted. The bot may also post a notice naming a banned person, with a link to their latest message, in the server's moderator channel; that is an ordinary Discord message in that server and the bot keeps no separate record of it.

3. Things the bot does without storing anything

Apart from being counted in the anonymous totals described in section 2g, nothing in this section is saved unless it says so.

  • Banned emojis. Messages and reactions are checked, in memory, against the server's banned-emoji list. Edits are checked only for messages still in the bot's temporary memory cache; the software the bot is built on keeps up to about 1,000 recent messages there, never writes them to disk, and loses them on restart. Edits to older messages aren't checked. If a non-moderator uses a banned emoji, the bot gives them the server's mute role and posts a notice in the server's moderator channel (who, where, which emoji and a link to the message). That notice is an ordinary Discord message in that server; the bot keeps no separate record. If it can't give the mute role, it remembers that person's user ID in memory for 10 minutes so it doesn't repeat the notice. Messages without a banned emoji are not kept.
  • Slurs. Messages sent to the bot are checked in memory against a list of slurs. A message that contains one is not answered normally and is never saved, but it counts as a warning, and repeated warnings lead to a temporary ban. That warning and ban record is the one exception to this section: it is saved on disk, as described in section 2h.
  • Short-term conversation memory. To understand follow-ups (for example, that "I take it back" means something different right after the bot told you off than right after it accepted your apology), the bot remembers, for each person in each channel, the kinds of its own last few replies to them, for 10 minutes. It does not remember what you wrote. This is held only in the bot's memory: it is never saved to disk, disappears when the bot restarts, and is switched off for anyone who has used /optout storage.
  • Welcome messages. If a server turns them on, the bot greets new members by mentioning them. Nothing about them is saved.
  • Commands. /ship, /femboyify, /dice, /fortune, /cats, /dogs, /mood, /define and similar are processed in memory and not saved. /define looks words up in a dictionary stored with the bot, so the word is not sent anywhere. /ship calculates its score from the two user IDs without storing them. If you use /optout ship, a separate one-way hash of your user ID is saved so nobody can ship you with someone else (you can still ship yourself); /optin ship or /forgetme deletes it.
  • Polls and challenges. /poll and asking for one in chat (for example "make a poll: pizza or pasta?") create one of Discord's own polls from the question and answers in that message. Discord keeps the votes and shows the results; the bot saves nothing about the poll or who voted. /challenge is a random roll that is not saved either.
  • Warframe commands. /baro, /cycles and the others fetch public game data from warframestat.us. No information about you is sent to it.
  • Drop look-ups. /drops and asking where to get something in chat (for example "where do I get Rhino Prime?") are answered from a copy of Warframe's official, public drop table. The bot downloads that file from its publisher now and then (an ordinary request for a public file that contains nothing about you), so the item name you type is not sent anywhere.
  • Item look-ups. /item sends what you typed in it (up to 40 characters) to warframestat.us. Asking in chat, for example "tell me about Soma Prime", sends the words only if they match the name of something in the bot's local copy of the drop table; otherwise nothing is sent. It is sent without your name, user ID, server or the rest of your message, and the bot does not save it; warframestat.us only sees the bot's own connection and handles requests under its own terms. If the drop table is unavailable, /drops also asks warframestat.us, and questions in chat aren't looked up at all. Answers are kept in the bot's memory for a few hours, so repeated questions don't contact it again.

4. Who it is shared with

Nobody, except:

  • Discord, which delivers the messages and commands (see Discord's own privacy policy);
  • the hosting provider where the bot's files are kept;
  • warframestat.us, the public game-data service, which receives only the look-ups described in section 3 (and the requests for world-state data);
  • Digital Extremes' public servers, which the bot contacts to download the public drop table (no information about anyone is sent);
  • AI development tools that may be used to assist in building and maintaining the bot (see below);
  • anyone to whom the law requires the operator to disclose information.

Information is never sold or used for advertising.

AI development tools. Third-party AI tools (such as Anthropic's Claude) may be used to assist the development and maintenance of the bot. Text people send with /feedback (the cleaned text, the date and the moderator flag) may be processed by those tools. Feedback entries never include user IDs, names or servers, and those tools are never given the opt-out hashes, the secret key used to make them, or the bot's login token. The bot itself does not send live messages to any AI service. Because feedback is anonymous, it is not possible to tell whose it is. These tools handle that text under their providers' own terms and privacy policies, which are outside our control; it is not used by us to train AI models. Please don't put personal information in feedback.

5. Your choices and rights

  • Messages you send to the bot in chat aren't saved. Use /optout storage at any time to stop /feedback saving anything from you, to turn off short-term memory and to be left out of the usage totals, and /optstatus storage to check.
  • Because feedback is anonymous, nothing links it to you, so the bot can't look up or delete entries by person. If you remember roughly when you sent something and what it said, contact the operator with the approximate date and wording. The operator can search for that wording and delete matching entries from the bot's files.
  • The usage totals in section 2g can't be linked to anyone, so there is nothing in them to look up or delete by person.
  • The bot deletes each feedback entry from its own files once it is 30 days old. That limit covers the bot's files only: it doesn't reach copies already processed by AI development tools (section 4), which can't be recalled, or information kept for the legal, safety or security reasons in section 2a.
  • To report one of the bot's pictures, right-click it and choose Apps > Report this image, or use /report. For anything serious, such as your own photo or illegal content, e-mail the contact at the top of this page.
  • You can ask the operator what information is held about you or to delete it, using the contact above. You don't need to contact anyone to delete the opt-out hash: /forgetme does it immediately (the operator can also remove it on request). Deleting it puts you back to the default. /forgetme doesn't delete a slur-warning or ban record (section 2h), which expires by itself within 7 days; if you believe it is wrong, ask the operator to delete it.
  • Server administrators can turn off the welcome message and the moderation features (/settings moderation can clear the mute role and notice channel), remove the bot from the server at any time, and ask the operator to delete the server's settings.

6. Security and retention

The bot's files are kept on a private server that only the operator can access. Feedback is deleted from the bot's files after 30 days (see section 5); opt-out hashes are kept until you opt in again or delete them with /forgetme; slur warnings are deleted after 24 hours and bans after 7 days at most; server settings, banned-emoji lists and moods are kept until the bot leaves the server; picture reports are kept until the operator closes them; anonymous usage totals are deleted after 12 months; the list of departed servers is kept only until their data is deleted. A copy of the public drop table is kept and replaced when a newer one is published (it contains no personal information). Backups of these files may exist for a short time.

If a server removes the bot. The server's saved data is deleted straight away if the bot is online when it is removed. If the bot is offline at that moment, the data stays until the bot next checks, which it does daily once it is running again, and it deletes the data of servers it hasn't been in for 7 days. To be sure that a server's data is deleted at once, contact the operator directly. This data contains no information about any person. The usage totals in section 2g don't record which server anything came from, so they stay until they expire.

7. Children

Discord requires its users to be at least 13 years old (or the minimum age in their country). The bot is not aimed at children and does not knowingly collect information from anyone under that age.
