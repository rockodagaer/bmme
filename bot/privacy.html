Fembot Privacy Policy

Effective date: 8 November 2026
Operator: __v33__
Contact: theaft3rmath@proton.me

Fembot is a small, hobby Discord bot: a joke chatbot with some Warframe information, a few fun commands and a few moderation tools. This page explains what it does with information. In short: it keeps very little, it keeps it anonymously where it can, and it never sells or shares it.

The same summary is available inside Discord with the /about command.

1. What the bot can see

To work, the bot must be allowed to read messages in the channels it can access (Discord's "Message Content" permission) and to see members and their roles (Discord's "Server Members" permission). It looks at most messages only for one purpose, the banned-emoji check described in section 3, and keeps nothing from them. It only *responds to* messages that mention it or reply to it.

2. What the bot stores

a) Messages the bot didn't understand (anonymous log). If you mention the bot or reply to it and it doesn't understand, the text may be saved to help improve it. Each entry contains only:

  • the message text, after the bot removes mentions, links (except links to well-known GIF sites, kept without their query strings), e-mail addresses and long numbers;
  • the date (no time of day);
  • whether it was a mention, a reply, or feedback;
  • optionally, which of the bot's own messages you replied to, and what that message said (the bot's own words, never yours);
  • a "moderator" flag if a moderator sent it using /feedback.

It does not contain your name, user ID, server, channel, message ID or exact time. Messages containing words on the bot's slur list are never saved. Entries are deleted automatically after 30 days. Text you send with /feedback is saved the same way (up to 1,000 characters).

The cleaning is automatic and cannot catch everything, for example a name typed in plain text, so please don't put personal information in messages to the bot.

The log is read by the operator only, for debugging and improving the bot. It may also be kept and used where necessary for legal, safety or security reasons, for example to investigate abuse or to respond to a lawful request.

b) Your storage opt-out. /optout storage stops the bot from saving any of your messages. To remember your choice, the bot stores a one-way keyed hash of your Discord user ID (not the ID itself) and nothing else about you. It is kept until you opt back in with /optin storage.

c) Server settings. For each server it is in, the bot stores the choices that server's administrators make with /settings: whether the welcome message is on, which picture it uses, and role and channel IDs (moderator roles, the mute role, the notice channel, roles /giverole may hand out). It also stores that server's banned-emoji list. This contains no information about any person. It is kept until the bot is removed from the server (or you ask for it to be deleted).

d) Mood. The bot has a daily "mood" number for each server. It stores only the server ID, the date and the number. It is nudged up or down by friendly or rude messages, but nothing about who or what caused it is kept.

3. Things the bot does without storing anything

  • Banned emojis. Messages, edits and reactions are checked, in memory, against the server's banned-emoji list. If a non-moderator uses a banned emoji, the bot gives them the server's mute role and posts a notice in the server's moderator channel (who, where, which emoji and a link to the message). That notice is an ordinary Discord message in that server; the bot keeps no separate record. Messages without a banned emoji are not kept.
  • Slurs. Messages sent *to the bot* are checked in memory against a list of slurs. If someone sends one, the bot does not answer normally and the message is not saved. If three such messages are sent in one server within an hour, the bot stops answering chat in that server for 30 minutes. For this it keeps only timestamps in memory (no user IDs, no text), which are lost when the bot restarts. It may post a notice (with a link to the latest message) in the server's moderator channel.
  • Welcome messages. If a server turns them on, the bot greets new members by mentioning them. Nothing about them is saved.
  • Commands. /ship, /femboyify, /dice, /fortune, /cats, /dogs, /mood and similar are processed in memory and not saved. /ship calculates its score from the two user IDs without storing them.
  • Warframe commands. /baro, /cycles and the others fetch public game data from warframestat.us. No information about you is sent to it.

4. Who it is shared with

Nobody, except:

  • Discord, which delivers the messages and commands (see Discord's own privacy policy);
  • the hosting provider where the bot's files are kept;
  • anyone to whom the law requires the operator to disclose information.

Information is never sold, used for advertising, or used to train machine-learning or AI models.

5. Your choices and rights

  • Use /optout storage at any time to stop your messages being saved, and /optstatus storage to check.
  • Because log entries are anonymous, the bot cannot find or delete one particular person's entries afterwards. Opting out prevents future saving, and everything is deleted after 30 days. If you believe an entry contains information about you, contact the operator with the approximate date and wording and it will be removed.
  • You can ask the operator what information is held about you or to delete it, using the contact above. For the opt-out hash, the operator can remove it on request.
  • Server administrators can turn off the welcome message and the moderation features, remove the bot from the server at any time, and ask the operator to delete the server's settings.

6. Security and retention

The bot's files are kept on a private server that only the operator can access. The anonymous log is deleted after 30 days; opt-out hashes are kept until you opt in again; server settings and moods are kept until the bot leaves the server. Backups of these files may exist for a short time.

7. Children

Discord requires its users to be at least 13 years old (or the minimum age in their country). The bot is not aimed at children and does not knowingly collect information from anyone under that age.

8. Changes

If this policy changes, the effective date above will be updated. Significant changes will also be reflected in /about.
